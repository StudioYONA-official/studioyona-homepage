# 앱 랜딩 페이지 한국어 문구 - 편집용

Date: 2026-07-31
Purpose: 4개 앱 랜딩 페이지의 한국어 문구를 직접 수정하기 위한 편집 원본.

## 편집 방법

- 이 문서의 문구를 고친 뒤 알려주면 한국어 HTML에 반영하고 영어 문구도 대응해 수정한다.
- 항목 이름(`Label`, `Title` 등)은 그대로 두고 콜론 뒤 문구만 고친다.
- 항목을 지우면 해당 요소를 화면에서 제거하고, 새 항목이 필요하면 자유롭게 적어도 된다.
- 법률 페이지 본문, EDSN Frame FAQ 15문항은 이 문서에 포함하지 않는다.

## 항목 이름 뜻

| 이름 | 화면에서의 위치 |
| --- | --- |
| Eyebrow | 앱 이름 위 작은 라벨 |
| H1 / H1 sub | 앱 이름과 괄호 부제 |
| Lead | 앱 이름 아래 소개 문장 |
| CTA | 버튼 문구 |
| Pill | 버튼 아래 작은 태그 |
| Summary | 히어로 오른쪽 요약 (라벨 / 값) |
| Label | 각 섹션 상단 작은 라벨 |
| Title | 섹션 큰 제목 |
| Lede | 제목 아래 설명 문장 |
| Fact | 숫자 강조 항목 (큰 글자 / 설명) |
| Rail | 스크롤 장면 왼쪽 진행 표시 |
| Step | 스크롤 장면의 각 단계 (제목 / 본문) |
| Case | 사용 사례 항목 (소제목 / 설명) |
| Spec | 사양 표 (항목 / 값) |

## 문체 기준

- 문장을 끝까지 맺는다. 명사로 끊지 않는다.
- `~합니다`, `~하세요`, `~할 수 있습니다`를 기본으로 쓴다.
- 앱이 무엇을 하는지 쓰고, 얼마나 공들였는지는 쓰지 않는다.
