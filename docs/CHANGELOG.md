# Changelog

## Unreleased

- 2026년 8월 29일 Spark Catcher 한국어·영어 개인정보처리방침과 이용약관에서 기능 명세처럼 보이거나 필요 이상으로 구체적인 설명을 줄이고, 실제 데이터 처리와 결제·외부 서비스·책임 범위를 중심으로 문구를 정리했다. 시행일과 개인정보처리방침 개정 이력도 함께 갱신했다.

- 2026년 8월 12일 Spark Catcher App Store 제출에 사용할 언어 중립 지원·개인정보처리방침·이용약관 진입 경로와 한국어·영어 전문 페이지를 추가했다. 개인정보처리방침은 회사가 직접 수신하는 고객지원 이메일·사용자 첨부·선택적 진단 정보와 기기·비공개 CloudKit·Apple 미리알림에서 처리되는 데이터를 구분하고, 항목·목적·1년 보유기간·파기·권리 행사·외부 처리 내용을 실제 앱 동작에 맞췄다. 이용약관은 무료 기능과 Pro 이용권, 자동 갱신 구독·비소모성 1회 구매, 해지·환불·구매복원, 구독 종료 후 기존 기록 유지, 선택적 Apple 서비스와 책임 범위를 규정했다. 기능 설명이나 적용 가능성이 낮은 권리 선언은 제거하고 개인정보처리방침 13개 항목, 이용약관 15개 조항으로 정리했다.

- 2026년 8월 7일 Veruma 한·영 개인정보처리방침을 차기 앱 동작과 맞춰 GitHub Pages production에 게시했다. 촬영본 저장용 사진 추가 권한과 사용자가 기기 사진 드로워를 열 때만 요청하는 읽기 권한을 구분하고, 허용된 전체·제한 사진의 기기 내 읽기 전용 열람과 개수 제한·마스킹된 로컬 진단, 사용자가 선택한 피드백 첨부·내보내기 내용을 반영했다. 시행일과 개정 이력도 2026년 8월 7일로 갱신했다.

- 2026년 8월 1일 영어 랜딩 페이지를 한국어와 대조해 어긋난 문구를 교정했다. 히어로 소개 문장 세 개가 2026-07-31 한국어 수정 이전 내용을 번역한 상태로 남아 있어 현재 한국어 기준으로 다시 썼다. 까꿍캠은 아이와 반려동물을 함께 다루도록 바꾼 한국어와 달리 영어가 아이 중심 서술로 남아 있던 부분(요약 카드, 사용 사례 2건)을 맞췄고, 흐름 섹션 제목도 다른 앱과 같은 형식으로 통일했다. EDSN Frame의 `N-cut`은 영어권에서 통하지 않는 표현이라 `multi-cut`으로, `hundred-day parties`는 `first milestones`로 바꿨다.

- 2026년 8월 1일 한국어 문장이 단어 중간에서 잘리던 문제를 고쳤다. 홈, 소개 페이지, 앱 페이지에 `word-break: keep-all`을 적용해 어절 단위로 줄바꿈하도록 하고, 상자보다 긴 단일 토큰만 `overflow-wrap: break-word`로 처리했다. 좁은 셀에 긴 값이 들어가는 법률 표의 `overflow-wrap: anywhere`는 그대로 두었다. 전역 스타일 변경이라 모든 페이지의 `site.css` 캐시 버전을 `20260801b`로 통일했다.

- 2026년 8월 1일 Veruma 상세 페이지의 스크린샷을 App Store 1.7 세트로 교체했다. `Studio YONA/tools/app-assets`의 `asc-current/IOS/1.7`에서 촬영, 셔터 갤러리, Fresco 필터 화면을 한국어·영어별로 가져왔다. 기존 1.0 세트와 달리 실제 피사체로 촬영한 화면이라 랜딩 본문의 필터 설명과 대응한다. Step 3이 `작품 정보 확인`에서 `아름다운 고퀄리티 필터`로 바뀐 뒤 맞지 않던 이미지도 이번에 해소했고, 이미지 실제 크기에 맞춰 `width`/`height` 속성을 646×1400으로 정정했다.

- 2026년 7월 31일 `docs/landing-copy-ko-edit.md`에서 수정한 문구를 4개 앱 랜딩 페이지의 한국어·영어에 반영했다. 각 앱의 도입부 라벨을 `왜 만들었나`에서 `어디서나 프레임?`처럼 앱 이름을 묻는 형태로 바꾸고, 히어로 eyebrow를 출시 순서(첫 번째~네 번째 앱)로 통일했다. 4개 앱의 `자세한 사양` 섹션과 EDSN Frame·탐정의 녹음기·까꿍캠의 `문의` 섹션을 제거했다. 탐정의 녹음기 주요 기능에서 `안전한 삭제`를 `위젯`으로 교체하고, 까꿍캠은 아이 중심 서술을 아이와 반려동물 양쪽으로 넓혔으며, Veruma는 필터를 앞세우는 구성으로 바꿨다. 소제목 없이 문장만 쓰는 목록을 위해 `facts-plain`과 `cases-plain` 스타일을 추가했다.

- 2026년 7월 31일 4개 앱 랜딩 페이지의 한국어 문구를 직접 편집할 수 있도록 `docs/landing-copy-ko-edit.md`를 추가했다. 히어로부터 사양 표까지 245개 항목을 HTML에서 그대로 추출했고, 항목 이름이 화면 어디에 해당하는지 표로 정리했다. 작업 중 스크롤 장면의 진행 표시(Rail) 문구가 각 단계 제목과 어긋난 것을 발견해 Veruma와 까꿍캠의 한국어·영어 항목을 맞췄다.

- 2026년 7월 30일 4개 앱 랜딩 페이지의 문구를 기존 사이트 카피의 문체에 맞춰 다시 썼다. 명사만 나열하고 마침표로 끊는 문장, 세 페이지에 반복되던 `~부터 ~까지` 대구, `조용하게 다듬었습니다` 같은 자기 미화 표현을 걷어내고 담백한 서술체로 바꿨다. 섹션 제목도 `정확한 조건`을 `앱 정보`로, `스크롤하며 따라가 보세요`를 `이런 순서로 씁니다`로 바꾸는 등 실제로 쓰는 말에 가깝게 정리했다. 사용자가 직접 작성한 히어로 lead와 FAQ 질문 목록은 그대로 두었다.

- 2026년 7월 30일 4개 앱 상세 페이지의 히어로를 아래 밴드와 같은 언어로 통일했다. 카드 두 개가 나란히 놓이던 구조를 전체 폭 다크 밴드로 바꾸고, 앱 이름을 큰 디스플레이 세리프로 키웠으며, 오른쪽 요약은 떠 있는 카드 대신 구분선으로 나뉜 조용한 행으로 정리했다. 히어로 전용 클래스 `hero-band`를 따로 두어 법률 페이지의 기존 히어로는 그대로 유지된다.

- 2026년 7월 30일 4개 앱 상세 페이지에 스크롤 기반 스토리텔링을 적용했다. 촬영/사용 흐름과 스크린샷 섹션을 하나의 스티키 장면으로 합쳐, 왼쪽 설명과 진행 표시가 고정된 채 오른쪽 화면이 순서대로 지나가도록 만들었다. 각 밴드와 목록은 뷰포트 진입 시 순차적으로 나타나며, `prefers-reduced-motion`에서는 모든 연출을 끄고 스티키도 해제한다. 관련 스타일은 `.scene`, `.scene-pin`, `.scene-steps`, `.scene-rail`과 `[data-rise]`, `[data-rise-group]`으로 정리했다.

- 2026년 7월 29일 4개 앱 상세 페이지를 카드 나열 구조에서 밴드 기반 랜딩 레이아웃으로 다시 만들었다. 밝은 샌드 섹션과 딥다크 섹션을 교차시키고, 스크린샷을 본문 하단 부록이 아니라 전용 다크 밴드의 주인공으로 배치했으며, 도입부에는 큰 서체의 단일 주장과 핵심 지표 3개를 두었다. 사용 흐름은 카드 대신 번호가 붙은 에디토리얼 행으로, 주요 기능은 큰 스크린샷과 나란한 2단 구성으로 바꿨다. 관련 스타일은 `.band`, `.flow`, `.showcase`, `.split`, `.facts`, `.cases`로 정리했다.

- 2026년 7월 29일 Veruma 상세 페이지에 스크린샷 섹션을 추가했다. `Studio YONA/tools/app-assets`의 App Store 제출 자산에서 촬영 화면, 아트 갤러리, 작품 상세를 한국어·영어별 3장씩 웹용으로 최적화해 배치했다. 이로써 공개 중인 네 개 앱 상세 페이지가 모두 스크린샷을 갖췄다.

- 2026년 7월 29일 까꿍캠 상세 페이지에 스크린샷 섹션을 추가했다. 앱 프로젝트의 실기기 캡처에서 설정 홈, 청각 효과, 시각 효과 화면을 한국어·영어별 3장씩 웹용으로 최적화해 배치했다. Veruma는 확보 가능한 캡처가 개발용 합성 컬러바 화면뿐이라 이번 작업에서 제외했다.

- 2026년 7월 29일 EDSN Frame, 탐정의 녹음기, 까꿍캠, Veruma 상세 페이지를 랜딩페이지 수준으로 확장했다. 각 앱마다 어떤 문제에서 출발했는지 설명하는 도입부와 4단계 사용 흐름, 구체적인 사용 사례 4종, 그리고 실제 사양을 정리한 표를 추가하고 주요 기능 목록도 앱 소스와 App Store 메타데이터 기준으로 구체화했다. 랜딩 섹션용 `story-panel`, `usecase-list`, `spec-rows` 스타일을 기존 카드 언어에 맞춰 추가했다.

- 2026년 7월 29일 앱 상세 페이지의 구조 격차와 끊긴 다운로드 경로를 정리했다. Veruma 페이지에만 없던 앱 요약 카드(한 줄 소개·출시 현황·지원 이메일)와 관련 문서 섹션을 다른 앱과 같은 구조로 추가하고, 실제 판매 중인 월간·연간·평생 상품을 `준비` 표현 대신 현재 제공 기준으로 서술했으며 호환성·언어·가격 항목을 채웠다. 탐정의 녹음기, 까꿍캠, Veruma 상세 페이지에도 App Store 링크를 추가해 홈에만 있던 다운로드 경로를 상세 페이지에서도 열었다.

- 2026년 7월 29일 EDSN Frame과 탐정의 녹음기 상세 페이지의 스크린샷 자리표시자를 실제 앱 화면으로 교체했다. `앱 화면을 미리 만나보세요`라는 안내와 달리 `Screenshot 01` 같은 빈 박스만 노출되고 있어, 각 앱 프로젝트의 최신 릴리스 스크린샷을 한국어·영어별 3장씩 웹용으로 최적화해 배치하고 설명 캡션과 대체 텍스트를 추가했다. 이미지가 없는 카드도 기존 자리표시자 형태를 유지하도록 스타일을 분기했다.

- 2026년 7월 29일 앱 목록 노출 일관성과 오래된 안내 문구를 정리했다. 홈에서 이미 숨긴 Stampho가 `/apps/`에는 카드와 히어로 CTA로 남아 있어 제거하고, 404 페이지의 `두 개의 앱` 안내를 현재 공개 중인 네 개 앱 기준으로 갱신했으며, 문의 페이지의 앱 목록과 고객지원의 기기 정보 안내(iOS 전용 → iOS 또는 Android)를 최신 상태로 맞췄다. `/apps/` 카드 태그도 앱별 실제 지원 플랫폼으로 정정했다.

- 2026년 7월 29일 앱 스토어 실측 기준으로 공개 페이지의 출시·호환 정보를 전면 교정했다. EDSN Frame 호환성을 iPhone·iPad·Mac(macOS 13.0 이상)·Android로 정정하고 홈과 상세 페이지에 App Store·Google Play 링크를 추가했으며, 이미 유료 판매 중인 까꿍캠의 `유료 앱 예정` 표기를 판매 중 상태로 정정했다.

- 2026년 7월 29일 EDSN Frame FAQ의 행사/매장 모드 관련 답변(5·6·7·8·9·11번)을 앱 2.5 기준 최신 사양으로 다시 썼다. 행사 모드에 구독 게이트가 없다는 점, 전달 방식 3종(QR·프린터·QR+프린터), 자동 복귀 기본 45초, 결과 편집 5~60초, 프린터 검색 기반 인쇄 가능 확인, 행사 결과물도 포토부스 필름을 소모한다는 조건을 반영하고, 판매 중단된 행사/매장 모드 월 구독 언급을 제거했다.

- 2026년 7월 29일 EDSN Frame FAQ 15문항의 한국어·영어 문구를 앱 실제 동작 기준으로 다시 썼다. 추측형 서술을 걷어내고 특수 프레임 3종, 자동 복귀 30~120초, 관리자 PIN 4자리, 행사/매장 모드 월 구독의 QR 전달 100회, QR 생성 팩 20/100/500/1,500회, 최초 설치 필름 3장, 출석 1장·광고 최대 2장, 새벽 4시 초기화, App Store 구독 해지 안내를 반영했다.
