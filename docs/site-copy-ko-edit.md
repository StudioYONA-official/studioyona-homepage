## Editing Rules

- 이 문서는 사용자가 직접 한국어 문구를 수정하기 위한 기준 파일이다.
- 법률 전문 페이지의 본문은 포함하지 않는다.
- `개인정보처리방침`, `이용약관` 같은 링크 라벨은 공개 페이지에 보이는 일반 링크 문구라 포함한다.
- 이 문서를 수정한 뒤 다시 전달하면, 수정된 한국어 문구를 HTML에 반영하고 대응 영어 문구도 자연스럽게 번역해 반영한다.
- URL, 이메일, 사업자 정보처럼 법적/운영 식별값에 가까운 항목은 문구 수정 전 실제 값 변경 여부를 확인한다.
