Spark Catcher?

Ideas vanish while you look for the right window

On Mac, press Control twice for a note or Option twice for a task. When you are done, you return naturally to what you were doing.

  • Double pressOpen Quick Note or Quick Task while another app is active
  • AutosaveNotes save as you type, while Cancel removes the unfinished draft
  • Always on topKeep an important note or task board visible above other Mac windows
How it works

From first thought to an organized list

Capture first, then add only the details you need.

  1. Open Quick Note
  2. Start a task in one line
  3. Organize everything together
01

Open Quick Note

Press Control twice on Mac, or tap Add Note on iPhone and iPad, and start typing right away.

02

Start a task in one line

Write the title first, then add a date, reminder, priority, or group only when it helps.

03

Find it all in one place

Filter or search notes, tasks, and scraps, with favorites kept close to the top.

Key features

Lightweight capture, one organized library

Creating and managing notes and tasks, along with the core global shortcuts on Mac, is free. Pro adds sync, pinned views, voice notes, more share formats, and themes.

  • Notes and tasks

    Add groups, schedules, reminders, and priorities only where they are useful.

  • Recent items and favorites

    Reopen recent entries quickly and keep favorites at the top of the list.

  • Scraps and search

    Collect webpages, shared links, and screen captures, then search their extracted text.

  • Connected devices

    With Pro, use iCloud and Apple Reminders to continue on supported devices.

Where it fits

For thoughts you do not want to lose

  • While working in another app

    Capture an idea without leaving the document or webpage in front of you.

  • When planning today

    Start with a title, then add time and reminders only to the tasks that need them.

  • When a note should stay visible

    Keep a reference note or task board above other Mac windows and edit it in place.

  • When collecting research

    Save webpages, links, and part of the screen as scraps that you can search later.
