탐정의 녹음기 개인정보처리방침

이 문서는 탐정의 녹음기 iPhone, iPad, Mac 앱에만 적용됩니다. Studio YONA는 녹음과 전사를 기기 안에서 처리하고, 분석 SDK와 회사 서버 업로드 없이 이메일 기반 지원을 제공하는 기준으로 앱을 운영합니다.

시행일: 2026년 5월 24일

스튜디오 요나(이하 "회사")는 탐정의 녹음기 iPhone, iPad, Mac 애플리케이션(이하 "앱") 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령에 따라 본 개인정보처리방침을 공개합니다.

1. 개인정보 처리방침 요약

  • 회사가 직접 수집하는 개인정보: 앱 내 구매 및 구독 권한 확인에 필요한 결제 확인 정보
  • 기기 안에서 처리되는 정보: 녹음 파일, 녹음 메타데이터, 전사 결과, 앱 설정, 선택적 위치 정보, 사용자가 직접 생성하는 진단 파일
  • 수집하지 않는 정보: 자체 회원가입 정보, 광고 식별자, 맞춤형 광고 정보, 제3자 분석 SDK를 통한 앱 사용 기록, 회사 서버로 자동 전송되는 녹음 파일·전사 결과·위치 정보·진단 로그
  • 제3자 제공: 회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 이용자가 공유 기능이나 파일 내보내기를 직접 선택하는 경우 선택한 대상의 정책에 따라 처리될 수 있습니다.
  • 처리위탁: 앱 내 구매와 구독 결제는 Apple Inc.가 처리합니다. 전사 처리는 앱에 포함된 온디바이스 모델로 수행되며 별도 전사 서버에 위탁하지 않습니다.
  • 문의 및 권리행사: studioyona.official@gmail.com

3. 처리하는 개인정보 항목

앱은 자체 회원가입을 요구하지 않으며, 회사 서버로 녹음 파일, 전사 결과, 위치 정보, 진단 로그, 앱 사용 기록을 자동 전송하지 않습니다. 회사는 앱 내 구매 및 구독 권한 확인에 필요한 결제 확인 정보만 처리합니다.

회사가 처리하는 결제 확인 정보

  • 구매 상품 식별자
  • 구매 상태, 구독 상태, 거래 식별자
  • 영수증, 구매 검증 토큰 또는 유료 기능 권한 확인에 필요한 App Store 거래 정보
  • 구매 복원, 환불, 구독 상태 확인, 결제 오류 대응에 필요한 최소한의 문의 정보

실제 카드번호, 계좌번호 등 결제수단 정보는 Apple이 처리하며, 회사는 이를 직접 수집하거나 저장하지 않습니다.

기기 안에서 처리되는 정보

  • 녹음 파일
  • 녹음 제목, 생성·수정 시각, 재생 길이, 즐겨찾기 여부, 삭제·복구 상태
  • 온디바이스 전사 기능으로 생성된 전사 텍스트, 전사 진행 상태, 전사 오류 상태
  • 카테고리, 폴더, 정렬, 저장 품질, 공유 포맷, 전사 기능 상태 등 앱 설정
  • 선택 기능을 켠 경우 녹음 시작 위치 정보
  • 사용자가 직접 생성하는 진단 파일

위 정보는 기본적으로 이용자의 기기 안에 저장됩니다. 전사는 앱에 포함된 Whisper 기반 온디바이스 모델로 처리되며, 회사는 이용자가 직접 공유, 내보내기, 문의 첨부 등 별도 동작을 실행하지 않는 한 녹음 파일이나 전사 결과에 접근하거나 수집하지 않습니다.

사용자가 직접 진단 파일을 제공하는 경우

진단 파일은 사용자가 앱에서 직접 내보내기를 실행할 때 기기 안에 생성됩니다. 사용자가 고객지원 문의 등을 통해 진단 파일을 직접 제공하는 경우 회사는 해당 문의 처리를 위해 다음 정보를 확인할 수 있습니다.

  • 앱 오류 기록, 작업 흐름 기록, MetricKit 진단 요약
  • 앱 버전, 빌드 번호, 기기 모델, 운영체제 버전
  • 앱에서 축약 또는 마스킹한 파일 경로 등 진단 정보

  • 회사가 보관하는 결제 확인 정보: 복구하기 어려운 방식으로 삭제 또는 비식별 처리
  • 앱 로컬 데이터: 사용자의 삭제 조작, 앱 데이터 삭제, 운영체제의 앱 삭제 절차에 따라 삭제
  • 전사 결과: 연결된 녹음 삭제, 전사 결과 삭제, 앱 데이터 삭제, 운영체제의 앱 삭제 절차에 따라 삭제
  • 법령상 보존이 필요한 정보: 해당 법령에서 정한 기간 동안 분리 보관 후 파기

  • 법령에 근거가 있거나 수사기관 등 공공기관의 적법한 요청이 있는 경우
  • 이용자가 별도로 동의한 경우

사용자가 공유 기능을 통해 선택한 앱, 사람, 저장 위치로 전송한 파일은 해당 대상의 정책에 따라 처리될 수 있습니다.

10. 자동 수집 장치 및 행태정보

현재 앱은 웹 쿠키, 맞춤형 광고, 광고 식별자(IDFA), 제3자 추적 SDK, 분석 SDK, 마케팅 SDK를 사용하지 않습니다. 온디바이스 전사 모델은 앱에 포함되어 제공되며, 전사 처리를 위해 녹음 파일이나 전사 결과를 회사 서버 또는 외부 전사 서버로 자동 전송하지 않습니다. 회사가 결제 확인 외의 자동 수집 장치를 도입하려면 사전에 처리방침을 개정하고 필요한 고지를 진행합니다.

11. 자동화된 결정

현재 앱은 이용자에게 법적 또는 중대한 영향을 미치는 자동화된 결정을 하지 않습니다. 온디바이스 전사 기능은 이용자가 선택한 녹음을 텍스트로 변환하는 보조 기능이며, 이용자의 권리·의무, 자격, 접근 권한, 결제 여부를 자동으로 결정하지 않습니다. 회사는 이용자의 녹음 파일이나 전사 결과를 AI 모델 학습에 사용하지 않습니다.
