탐정의 녹음기

‘새로운 녹음 1, 2, 3’으로 쌓이는 기본 녹음기나 매달 구독료를 내고 외부 서버에 음성을 올리는 회의록 앱 대신 쓸 수 있는 녹음기입니다. 강의·회의·인터뷰·상담 주제를 누르면 그 폴더에 바로 녹음되고, 외부 전송 없이 기기 안에서 텍스트로 변환합니다.

탐정의 녹음기의 방식

녹음 시작과 동시에 끝나는 폴더 분류와 기기 내 전사

급하게 녹음부터 눌러 두고 나중에 정리하려다 보면 날짜만 적힌 파일 수백 개가 한 목록에 섞입니다. 탐정의 녹음기는 그룹과 카테고리로 나눈 주제를 누르는 즉시 해당 폴더에 순번을 붙여 녹음을 시작하고, 종료 후에는 외부 클라우드로 음성을 보내지 않고 기기 안에서 바로 텍스트로 변환합니다.

  • 1탭 분류 녹음주제를 누르면 바로 녹음이 시작되고 카테고리 이름과 순번이 자동으로 붙습니다
  • 기기 내 텍스트 변환iPhone·iPad 온디바이스 엔진과 Mac 로컬 Whisper로 외부 서버 전송 없이 전사합니다
  • 구간 자동 복구녹음 중 5~30초마다 체크포인트를 남겨 배터리가 꺼져도 직전 구간까지 복구합니다
사용 흐름

주제 선택부터 텍스트 검색까지

폴더를 고르거나 파일 이름을 입력하느라 중요한 대화 앞부분을 놓치지 않습니다.

  1. 그룹·카테고리 구성
  2. 1탭 즉시 녹음·자동 저장
  3. 기기 내 전사·본문 검색
  4. 편집·공유 및 iCloud 동기화
01

2단 그룹·카테고리 구성

전공 수업, 주간 회의, 취재 인터뷰, 현장 점검처럼 반복해서 녹음하는 주제를 2단 구조(그룹 > 카테고리)로 나눠 배치합니다.

02

카테고리 탭 즉시 녹음과 구간 임시 저장

앱 안의 카테고리뿐 아니라 잠금화면·홈 화면 위젯과 앱 아이콘 빠른 동작에서도 한 번에 녹음을 시작합니다. 녹음 중에는 구간별로 임시 저장되어 앱이 비정상 종료되어도 다시 열 때 복구합니다.

03

녹음 직후 또는 충전 중 텍스트 변환

녹음이 끝나자마자 자동 변환하거나, 배터리를 아끼도록 충전 중일 때만 일괄 변환하게 설정할 수 있습니다. 변환된 텍스트로 필요한 발언만 빠르게 찾아 읽습니다.

04

기기 내 보관과 개인 iCloud 동기화

음성과 전사문은 외부 서버로 전송되지 않습니다. 기기 내부에 보관하거나 내 Apple 계정의 개인 iCloud로 iPhone·iPad·Mac 간 동기화할 수 있고, 최근 삭제함(보관 기간 선택)으로 실수로 지운 파일도 복원할 수 있습니다.

주요 기능

장시간 녹음과 사후 정리 도구

현장 녹음의 안정성과 녹음 이후 편집·분류 기능을 함께 갖췄습니다.

  • 잠금화면·홈 화면 위젯과 빠른 시작

    잠금화면 위젯과 홈 화면 위젯(소·중), 앱 아이콘 길게 누르기로 원하는 카테고리의 녹음을 즉시 시작합니다.

  • 이어 녹음·구간 자르기·음질 선택

    기존 녹음 파일 뒤에 이어서 녹음(Append)하거나 앞뒤 불필요한 구간을 다듬고(Trim), 고효율(AAC)·표준·무손실(Apple Lossless) 음질 중 용도에 맞게 선택할 수 있습니다.

  • 무음 자동정지·시작 위치 기록·일괄 이동

    말이 멈추면 설정한 시간(10초~10분) 뒤 자동으로 녹음을 마치는 무음 자동정지, 녹음 시작 시점의 도로명·지번 주소 기록 옵션, 여러 파일의 카테고리 일괄 이동·공유를 지원합니다.

활용 장면

주요 활용처

  • 외부 유출이 걱정되는 회의·인터뷰·상담

    클라우드 전사 서비스에 올리기 어려운 보안 회의, 취재 인터뷰, 법률·심리 상담 녹음을 기기 안에서만 안전하게 텍스트로 변환합니다.

  • 과목마다 쌓이는 대학 강의와 세미나

    학기 초에 과목별 카테고리를 만들어 두면 한 학기 녹음이 과목별로 자동 정리되고, 시험 기간에는 텍스트를 읽으며 복습할 수 있습니다.

  • 일시정지 뒤 이어 찍거나 길게 녹음하는 현장

    쉬는 시간 뒤 기존 파일에 이어서 녹음하고, 5~30초 단위 자동 체크포인트 덕분에 2시간짜리 긴 녹음도 유실 걱정 없이 남깁니다.

  • 운전·이동 중 남기는 음성 메모

    위젯으로 한 번에 녹음을 켜고 무음 자동정지를 설정해 두면, 말이 끝난 뒤 버튼을 다시 누르지 않아도 알아서 저장됩니다.
