탐정의 녹음기?

녹음 파일을 찾느라 헤맨 적 있으신가요

파일이 쌓이면 비슷한 제목 사이에서 필요한 파일을 다시 찾기 어렵습니다. 그래서 녹음을 시작할 때 어디에 넣을지 먼저 정하도록 만들었습니다. 카테고리를 누르면 바로 녹음이 시작되고, 녹음을 끝내면 이미 정리되어 있습니다.

  • 한 번의 탭카테고리를 누르면 그 자리에서 녹음이 시작됩니다
  • 온디바이스전사는 기기 안에서 처리하고 외부로 보내지 않습니다
  • 2단 구조그룹과 카테고리로 묶어서 목록이 길어져도 찾기 쉽습니다
사용 흐름

이렇게 사용하세요

실제 앱 화면과 함께 사용 순서를 정리했습니다.

  1. 그룹과 카테고리 만들기
  2. 눌러서 바로 녹음
  3. 텍스트로 확인
  4. 기기 안에 보관
01

그룹과 카테고리를 만듭니다

강의나 회의, 인터뷰처럼 자주 녹음하는 주제를 미리 만들어 두세요. 그룹으로 묶으면 목록이 길어져도 찾기 쉽습니다.

02

누르면 바로 녹음됩니다

카테고리를 누르면 바로 녹음이 시작됩니다. 저장 위치를 고르거나 이름을 짓지 않아도 되니 놓치는 순간이 줄어듭니다.

03

텍스트로 확인합니다

전사된 내용을 읽으면서 필요한 부분만 찾을 수 있습니다. 처음부터 다시 들을 필요가 없습니다.

04

기기에만 저장됩니다

녹음 파일과 전사 결과는 기기에 저장되고 외부 전사 서버로 보내지 않습니다. 실수로 지워도 최근 삭제에서 되돌릴 수 있습니다.

주요 기능

많이 쌓여도 찾기 쉽습니다

녹음이 늘어날수록 정리가 중요해집니다. 검색과 즐겨찾기, 일괄 처리와 복원 기능을 넣었습니다.

  • 검색과 즐겨찾기

    라이브러리에서 검색할 수 있고 자주 듣는 녹음은 즐겨찾기로 모아 둘 수 있습니다.

  • 편집과 일괄 처리

    구간을 자르거나 이어서 녹음할 수 있고, 여러 녹음을 한 번에 옮기고 공유할 수 있습니다.

  • 위젯

    홈 화면은 물론 잠금화면에서도 바로 녹음을 시작할 수 있습니다.

이럴 때

이럴 때 쓰면 좋습니다

  • 강의와 수업

    과목별로 카테고리를 만들어두면 학기 내내 같은 자리에 쌓입니다. 시험 기간에 필요한 회차만 골라 들으세요.

  • 회의와 인터뷰

    프로젝트별로 묶어 두고 끝난 뒤 전사를 훑으면서 필요한 부분만 찾을 수 있습니다.

  • 현장 기록

    답사나 점검처럼 나중에 근거가 필요할 때 씁니다. 위치 저장을 켜면 어디서 녹음했는지도 남습니다.

  • 생각 정리

    떠오른 아이디어를 말로 남겨 두세요. 무음 자동정지를 켜두면 말이 끝난 뒤 알아서 멈춥니다.
