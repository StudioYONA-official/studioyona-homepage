Spark Catcher의 방식

창 전환 없는 즉시 입력과 화면 위 고정 보드

문서를 읽거나 코딩·회의를 하다가 다른 앱을 찾으려 창을 바꾸면 하던 일의 맥락이 끊깁니다. Mac에서는 어떤 전체 화면 앱 위에 있든 `Control` 두 번으로 메모를, `Option` 두 번으로 할 일을 바로 열고, 닫는 즉시 원래 쓰던 앱과 커서 위치로 돌아갑니다.

  • 보조 키 두 번`Control×2` 메모, `Option×2` 할 일, 길게 눌러 방금 적은 항목 다시 열기
  • 원키 화면 스크랩선택 문장(`⌃⌥⌘C`), 화면 영역 캡처+한·영 OCR(`⌃⌥⌘S`), 웹 본문 클리핑
  • 무료 고정 보드명령 팔레트(`Control+Option×2`)에서 `Space`로 메모·할 일 보드를 창 위에 고정
사용 흐름

빠른 입력부터 고정 보드 관리까지

폴더나 양식을 먼저 고르지 않고 바로 입력창을 열어 기록합니다.

  1. 보조 키·위젯으로 즉시 입력
  2. 한 줄 할 일과 상단 고정 보드
  3. 메모·할 일·OCR 스크랩 통합 검색
01

보조 키 두 번과 4버튼 위젯 실행

Mac에서는 `Control`·`Option` 두 번으로 입력창을 열고 `/`를 입력해 자주 쓰는 템플릿을 불러옵니다. iPhone·iPad에서는 메모·할 일·음성 메모·음성 할 일 4버튼 위젯으로 홈 화면에서 바로 작성합니다.

02

한 줄 할 일 작성과 상단 고정 보드

제목만 먼저 적고 마감일·알림·우선순위·그룹은 필요한 항목에만 추가합니다. 오늘 처리할 할 일 보드를 화면 위에 고정해 두면 체크해서 완료하는 즉시 보드에서 정리됩니다.

03

메모·할 일·캡처 OCR 통합 검색

`⌃⌥⌘S`로 드래그해 캡처한 화면 속 한국어·영어 텍스트(기기 내 OCR), Safari 읽기 도구로 가져온 웹 본문, 일반 메모와 할 일을 한 목록에서 검색합니다.

주요 기능

단축키·고정 보드는 무료, 기기 간 동기화·외부 연동은 Pro

메모·할 일 무제한 작성, Mac 전역 단축키, 명령 팔레트, 상단 고정 보드, 5가지 테마는 무료 버전에서 제한 없이 쓸 수 있습니다. Pro 기능은 카드 등록이나 자동 결제 없는 14일 체험으로 먼저 확인할 수 있습니다.

  • 드래그 문장·Safari 본문·화면 영역 OCR 스크랩

    보고 있는 화면에서 단축키 한 번으로 선택 텍스트(`⌃⌥⌘C`)와 화면 영역 캡처(`⌃⌥⌘S`)를 저장하고, Safari 공유 시트로 광고를 뺀 본문과 마크다운 링크를 스크랩합니다.

  • 명령 팔레트와 항상 위 고정 보드 (무료)

    `Control+Option`을 두 번 눌러 명령 팔레트에서 기록을 즉시 검색하고, `Space`를 눌러 참고 메모나 체크리스트를 전체 화면 앱 위에 반투명 보드로 띄워 둘 수 있습니다.

  • Apple 미리알림 양방향 연동 · 캘린더 · Markdown 폴더 동기화 (Pro)

    Apple 미리알림과 양방향 동기화(중복 알림 방지 지원)하고 캘린더에 일정을 표시하며, Obsidian 등 외부 편집기에서 바로 열 수 있는 로컬 `.md` 폴더 양방향 동기화를 지원합니다.

  • 기기 내 음성 입력 · 의미 기반 관련 검색 · 클라우드 동기화 (Pro)

    음성 파일을 남기지 않는 온디바이스 음성 인식으로 메모·할 일을 말로 적고, NLEmbedding 기반 관련 기록 찾기·자동 그룹 추천과 iCloud(또는 암호화 Google Drive) 동기화를 제공합니다(월간·연간 또는 1회 평생 구매).

활용 장면

주요 활용처

  • 개발·문서 작성·화상 회의 중 떠오른 할 일

    IDE나 브라우저, 회의 화면을 벗어나지 않고 `Option` 두 번으로 후속 할 일을 적어 둔 뒤 바로 원래 창으로 돌아갑니다.

  • 모니터 한쪽에 오늘 체크리스트를 띄워 둘 때

    할 일 보드를 화면 위에 고정해 두고 하나씩 체크해 지워 나가며, 참고할 메모도 옆에 함께 띄워 둡니다.

  • 논문·레퍼런스 문구와 표 이미지를 모을 때

    웹 문장은 `⌃⌥⌘C`로, 텍스트 선택이 안 되는 영상 자막이나 표는 `⌃⌥⌘S` 화면 캡처로 저장해 두고 이미지 속 단어로 다시 검색합니다.

  • iPhone 위젯과 Mac·Obsidian을 함께 쓸 때

    이동 중에는 iPhone 음성 할 일 위젯으로 남기고, 책상 앞에서는 Mac과 Apple 미리알림, 로컬 Markdown 폴더로 이어서 관리합니다.
